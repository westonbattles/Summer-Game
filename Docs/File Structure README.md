`#Game` Folder is the main folder that contains folders for each asset.
- Characters
- Environment
- Props
- UI
Sub-directories within each of the game folders will have their own respective folder for game assets.

As of 6/18/26 the *recommended* way to make a new feature is to add it to the `#game` folder as its own subdirectory and then add in all of the assets.

Currently, there is a folder named `Scripts` which contains subdirectories for each game feature and/or asset.
